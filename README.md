# ByClick
Plataforma de E-commerce de Angola

Resumo da Proposta:
Assunto: Uma plataforma de e-commerce e serviços que conecta empresas, autónomos e particulares a clientes finais através de geolocalização e filtros inteligentes de preço.

Diferencial: O uso do Python (via FastAPI) será fundamental para criar o motor de busca e filtragem por preço e localização, garantindo que o app entregue exatamente o que cabe no bolso do utilizador.

Logística: Foco em eliminar a barreira da distância com um sistema de entregas integrado, o que aumenta a confiança em itens de segunda mão.
